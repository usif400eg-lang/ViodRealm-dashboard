Minecraft server control panel

A Minecraft server panel that takes backups you can actually restore

VoxelPanel controls your Paper servers from your browser: live console, full file manager, player and world tools, and whole-server backups that sync to Google Drive or OneDrive with verified checksums.

Read the docs
  • Every file under the server root, no exclusions
  • SHA-256 verified, resumable transfers
  • Per-server permissions for collaborators

Minecraft backups to Google Drive and OneDrive, with the details that decide whether a restore works

Full coverage, by default

Archives worlds, plugins, configs, and logs — every file under the server root, with no silent exclusions.

Verified, not assumed

Hashes every archive byte-for-byte with SHA-256 so a corrupted backup is caught before you ever need it.

Resumable cloud sync

Chunked uploads that survive dropped connections and pick up exactly where they left off.

Download any backup, any time

Stream any backup straight to your browser, with its SHA-256 shown so you can verify the file yourself.

Scheduling and retention

Interval or cron schedules with protected retention, so important backups are never rotated away.

Visible progress and real failures

Step-by-step reporting for archiving and uploading — real errors surfaced, never a silent "done".

Everything else you need to run a server

Live console

Real-time log streaming over WebSocket with command execution and history.

Complete file manager

Browse the whole server directory and edit configs safely in place.

Players & worlds

Kick, ban, teleport, gamemode, plus time, weather, and world controls.

Performance metrics

Live TPS, MSPT, CPU, heap and GC with historical charts.

Accounts & audit log

Granular per-server accounts with an auditable log of every action.

Pixel-accurate inventory viewer

Inspect a player's real inventory, armor, enchants and durability, like the game.

Share a server without sharing your account

  • Invite by usernameAdd collaborators directly — no shared passwords, ever.
  • Preset rolesAdmin, Moderator, Operator, Viewer — or a custom set of permissions.

Two things it deliberately cannot do

It won't start a fully stopped server on its own

Power-on needs a running companion plugin or your hosting panel. A panel can't wake a process that isn't there — so we're honest about it instead of failing silently.

It won't do risky in-place restores while running

Restores stop the server first and verify the archive, so you never overwrite live world data mid-write and corrupt it.

سياسة العقدة (Node Policy)

                

                    

                        
                        
                        أمر جذر واحد في كل سطر. ترفضه العقدة بغضّ النظر عن صلاحيات اللوحة.
                    

                    

                        
                        
                        اتركه فارغاً لكشف كامل مجلد السيرفر (الافتراضي). أضف مسارات نسبية لتضييقه. تتحقق العقدة من كل مسار على حدة.
                    

                


                

                    
ماذا يحدث بعد ذلك

                    
تُعيد اللوحة توكن عقدة يُعرض مرة واحدة بصيغة vp_<publicId>_<secret>. ضعه في
                    web.token داخل plugins/VoxelPanel/config.yml على سيرفر Paper وأعد تشغيله؛ عندها يسجّل البلجن نفسه،
                    ويبدأ في بثّ بياناته الحية للوحة تلقائياً.

                


                

            


            

                
                
            

        

    


    
    

        

            

                

                    
                    

                        
تم إنشاء السيرفر — انسخ التوكن الآن

                        
الصق هذا التوكن في إعداد بلجن VoxelPanel على سيرفر Paper. يُعرض مرة واحدة فقط.

                    

                

                
            


            

                

                    

                        توكن التفعيل
                        
                    

                    

                    
لا تُخزَّن هذه القيمة بشكل مقروء في أي مكان. إذا فقدتها، عليك إعادة توليد التوكن وتحديث البلجن مجدداً.

                


                

                     إعداد البلجن الجاهز للّصق
                    
                

                

                    

                

                
web.url هو عنوان الواجهة الخلفية الذي يتصل به السيرفر. يجب أن يتمكّن سيرفر Paper من الوصول إليه.

                
ترفض اللوحة عمداً قراءة أو كتابة هذا الملف عبر مدير الملفات، فلا يمكن تسريبه من خلال الـ sandbox.
